# D209 – Data Mining I

**WGU Master of Science in Data Analytics**

## Overview
Applied unsupervised data mining techniques to discover hidden patterns in telecom customer data using association rule mining and classification.

## Tasks
### Task 1 – Association Rule Mining
- Prepared transaction-style dataset from telecom churn data
- Generated association rules using the Apriori algorithm
- Evaluated rules by support, confidence, and lift
- Identified meaningful relationships between customer attributes

### Task 2 – Classification
- Split data into training and test sets
- Built a classification model to predict customer churn
- Evaluated model performance on held-out test data
